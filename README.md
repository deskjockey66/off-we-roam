# Off We Roam

A family travel journal, destination guide and itinerary collection. Hosted free on GitHub Pages.

## Update from your phone

Open https://app.pagescms.org/ and select `deskjockey66/off-we-roam`, branch `main`. Choose Stories, guides and itineraries to edit or add an article and upload your photos. Save with Publish enabled to update the website. Homepage and Our story have their own editors.

## Build

Install `requirements.txt`, then run `python build.py`. Output is `_site`; `SITE_BASE_PATH` defaults to `/off-we-roam`. The GitHub Actions workflow uses the current Pages base path automatically.

Only family-supplied photographs are included. Booking guidance was checked against the linked operators on 15 October 2026 and must be refreshed as seasons change. No next-season release dates are assumed.
